# AdsAgent Notifications

1. List existing integrations and read runtime monitoring capabilities before
   describing coverage.
2. Use only masked destinations, public refs, and operator-scoped advertised
   tools. Never solicit hidden credentials in chat.
3. For changes or test delivery, prepare exactly one action, show the sanitized
   summary, obtain explicit approval, and confirm once.

   destination delivery.
5. Never replay an uncertain confirm or change customer FB User permissions.

event coverage, thresholds, channel configuration, webhook subscription, test
