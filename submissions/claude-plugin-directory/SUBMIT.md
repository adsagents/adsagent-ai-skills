# Claude Plugin Directory Submission

Portal: https://claude.ai/directory/manage/new

Choose **Bundle** (GitHub-hosted skills and MCP connections).
**Connector only** submits one remote MCP separately.

## Published plugin tree

Directory review scans the marketplace plugin `source`.
`.claude-plugin/marketplace.json` keeps the plugin name `adsagent` and sets `"source": "./plugin"`.

`plugin/` is generated by `python3 scripts/sync_claude_plugin_tree.py` from three sources:

- `.claude-plugin/plugin.json`
- `.mcp.json`
- `skills/` (skill markdown, including files those skills reference)

Do not hand-edit `plugin/`. Commit the script output. The validate workflow runs
`python3 scripts/sync_claude_plugin_tree.py --check` and fails when `plugin/` drifts,
when a file under `plugin/` reads `os.environ` or `getenv`, or when it references
an image or font (png, ttf, and the same class of files).

These paths stay at the repository root, outside the scanned plugin source:
`scripts/`, `tests/`, `submissions/`, `docs/`, `Dockerfile`, `skill_pack_mcp/`,
`.cursor-plugin/`, and `assets/`. Cursor still reads `.cursor-plugin/plugin.json`,
root `mcp.json`, root `skills/`, and `assets/logo.png`. Codex marketplace installs
use the same `adsagent` entry, so they receive this generated tree. A plain skills
clone and the Glama image still read root `skills/`.

Install commands stay `claude plugin marketplace add adsagents/adsagent-ai-skills`
and `claude plugin install adsagent@adsagent`.

## Pre-submit

```bash
python3 scripts/sync_claude_plugin_tree.py --check
claude plugin validate .
claude plugin validate ./plugin
python3 scripts/validate_tri_channel_pack.py
python3 -m pytest -q
```

## Short description

AdsAgent tri-channel Claude plugin: hosted OAuth MCP for Meta, Google Ads, and TikTok plus behavior skills for bounded reads and safer prepare/confirm ad workflows.

## Portal pitfalls

- **`plugin_homepage`**: Anthropic API rejects spaces/control characters. Use exactly `https://adsagent.md/connect` with no leading/trailing spaces. Do not paste two URLs, markdown links, or display names into this field.

- Root `.mcp.json` declares HTTP MCP URLs only (no `Authorization` header).
- License is MIT (`LICENSE`).
- This is separate from Connectors Directory MCP server registration on `adsagent.md`.
